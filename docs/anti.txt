# MODULE AUTHENTICATION

## NGUYÊN TẮC

Authentication là điểm chạm đầu tiên của người dùng với hệ thống.

Mục tiêu:

* Tạo cảm giác chuyên nghiệp ngay từ lần truy cập đầu tiên.
* Tăng độ tin cậy.
* Làm nổi bật giá trị của EduGuard.
* Thiết kế theo phong cách SaaS hiện đại.
* Không giống form đăng nhập đồ án sinh viên.

LƯU Ý:

Chỉ được phép thay đổi:

* UI
* UX
* Layout
* Component
* Animation
* Responsive

KHÔNG được thay đổi:

* Logic đăng nhập
* Logic đăng ký
* API
* OAuth
* OTP
* Validation business
* Authentication flow
